El orden de trabajo

Negocio y mercado → investigación → agrupación de búsquedas → mapa aprobado → ficha de cada página → contenido y código → verificación → medición.

Decisiones que faltan

  • Servicios prioritarios, cliente ideal y zonas atendidas.
  • Dominio preferido y datos de contacto reales.
  • Investigación con fuente, fecha, demanda e intención.
  • Resolver solapamientos entre servicios de auditoría y entre Tributos y Cumplimiento tributario.

El mapa visual y el sitemap XML son entregables distintos. El XML incluirá solo URLs aprobadas e indexables; las candidatas no entrarán automáticamente.

Mapa heredado

Inicio → categoría → servicio. La jerarquía SEO final se decide después de investigar.

Hitos con evidencia

Los estados son declarados manualmente. «Listo para revisión» requiere revisar la evidencia; no equivale a producción verificada.
