GitHub muestra el código HTML, no lo ejecuta como aplicación. Para usar el panel, abrir el archivo de un clon local en el navegador. No se ha desplegado una pestaña de una aplicación ni un panel privado. Esta sección de GitHub es navegable desde [Gestión](../../gestion/README.md).

## Método y fuentes

Activar [seo-orquestador en IA Manager](https://github.com/datawescalona/ia-manager/blob/main/core/skills/seo-orquestador/SKILL.md). Consultar siempre [System SEO](https://github.com/datawescalona/system-seo) en vivo, ejecutar su comprobación de coherencia y leer el arnés del módulo elegido antes de completar una etapa. No replicar sus arneses aquí.

Primero negocio y palabras clave; después intención, agrupación SERP y arquitectura. Las 23 candidatas del menú no equivalen a páginas SEO aprobadas. Los controles técnicos acreditan implementación, no garantizan posiciones.

## Fuente de estado

`data/tasks.json` conserva el seguimiento revisado. Las fichas del panel son borradores hasta que el PM las revise y versione. El sitemap XML público se preparará después de confirmar dominio y páginas aprobadas, sin candidatas, rutas de error ni archivos de gestión.
